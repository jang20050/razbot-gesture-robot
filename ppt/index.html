손짓으로 마음을 읽어요

  • 카메라 + 손 관절 21개 인식 (MediaPipe)
  • 손 모양: 주먹 ✊ 가위 ✌️ 보 ✋ 엄지 👍 …
  • 손 움직임: 빠르게 흔들기 = 인사, 천천히 = 쓰담쓰담, 주먹 휘두르기 = 위협

몸 전체로 감정을 보여 줘요

  • 😊 OLED 표정 9가지 애니메이션
  • 🛞 몸짓: 기쁘면 들썩, 부끄러우면 뒷걸음, 삐지면 등 돌리기
  • 🔔 부저 횟수 + 🎵 목소리(꽥꽥·짹짹·구구)

관계가 쌓일수록 더 깊어져요

  • 함께한 시간·교감 → 호감도 → 레벨 1~10
  • 레벨이 오를수록 할 수 있는 교감이 늘어나요
  • 🎓 개인기 훈련 · 📸 추억 · 🪪 라즈봇 카드
🔁 알아차리고 → 표현하고 → 자라는 과정이 계속 순환하며 관계가 됩니다

하드웨어 구성

📷 USB 웹캠

640×480, 초당 약 15~30프레임. 손 모양과 움직임을 봐요.

😊 OLED 화면

SSD1306 128×32, I2C 주소 0x3C. 라즈봇의 얼굴이에요.

🛞 바퀴 4개 + 모터

라즈봇 V2 확장보드 (I2C 0x2B)로 제어. 감정을 몸짓으로 보여 줘요.

🔔 부저

켜고 끄기만 되는 한 음 부저 → 감정을 울리는 횟수와 길이로 표현해요.

🍓 라즈베리파이 5

8GB, Debian 13. 손 인식·감정 엔진·웹 서버가 모두 여기서 돌아가요.

블록을 누르면 설명이 나와요
app.py 카메라를 켜고 끌 수 있고, 프레임마다 손 인식으로 넘겨요.
gesture.py MediaPipe HandLandmarker로 손가락 관절 21개의 위치를 찾아요.
gesture.py 펴진 손가락으로 모양을, companion.py가 시간에 따른 움직임(흔들기·쓰다듬기·휘두르기)을 판정해요.
companion.py 손짓을 감정 반응으로 바꾸고, 지금 기분(기쁨·삐짐·졸림…)을 기억해서 평소 행동까지 바꿔요.
face.py OLED에 표정 애니메이션을 그려요 (웹 화면에도 같은 얼굴).
robot.py I2C로 모터 4개를 제어해 기분별 몸짓을 해요.
robot.py 부저 횟수 규칙 · voice.js 브라우저에서 목소리 합성.
petgame.py 호감도·레벨·해금·훈련·할 일·앨범을 관리하고 저장해요.
web/ 게임 화면. 로봇이 직접 보여 주거나 Vercel·GitHub Pages에서 로봇에 연결해요.
