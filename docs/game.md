# 🎮 라즈봇 키우기 — 게임 설명서

라즈봇을 **반려동물처럼 키우는 감정 교류 게임**입니다.
같이 시간을 보내고, 손짓으로 교감하고, 개인기를 훈련시키면 **호감도(XP)** 가 쌓이고,
**레벨이 오를수록 라즈봇과 할 수 있는 교감이 늘어납니다.**

---

## 1. 실행하기

### 🌐 웹사이트: **https://razbot-game.vercel.app** · **https://jang20050.github.io/razbot-gesture-robot/**
게임 화면은 Vercel과 GitHub Pages에 올라가 있고(둘은 같은 화면이에요), **라즈봇(또는 PC)에서 돌아가는 `app.py`와 연결**해서 놀아요.
사이트는 화면만 보여 주고, 손 인식·로봇 제어·저장은 연결된 라즈봇이 해요. 처음 열면 **🔌 라즈봇 연결** 창이 나와요.

| 라즈봇 프로그램이 도는 곳 | 연결 주소 | 준비 |
|---|---|---|
| 💻 지금 이 PC (`play_pc.bat`) | `http://localhost:5000` | 브라우저가 **"로컬 네트워크의 기기에 액세스"** 권한을 물으면 **허용**. 안 되면 연결 창의 **"💻 이 PC의 게임 화면 바로 열기"** |
| 🤖 라즈베리파이 | `./tunnel.sh` 가 알려 주는 `https://….trycloudflare.com` + **접속 코드** | 라즈베리파이에서 `./tunnel.sh` 실행 |

- 사이트가 **https**라서, 같은 와이파이라도 `http://192.168.…` 주소에는 브라우저가 연결을 막아요 → 라즈베리파이는 터널을 써요.
- `tunnel.sh` 는 Cloudflare 무료 터널(계정 필요 없음)을 열고, 처음 실행할 때 **접속 코드**를 만들어요(`.token`).
  터널로 들어오는 요청은 접속 코드가 있어야만 통과해요. 같은 와이파이/같은 PC에서 직접 여는 건 지금처럼 코드 없이 돼요.
- 터널 주소는 켤 때마다 바뀌어요. 끄려면 `tunnel.sh` 창에서 Ctrl+C.
- 연결 정보는 브라우저에 기억돼서 다음에 열면 자동으로 다시 연결해요. 바꾸려면 오른쪽 위 **🔌** 를 눌러요.
- 이미 권한을 차단했다면: 주소창 왼쪽 자물쇠(사이트 정보) → 사이트 설정 → **로컬 네트워크 액세스** → 허용.
- 라즈봇 주소로 바로 열어도 돼요: `http://<라즈베리파이 IP>:5000/game` (같은 와이파이), `http://localhost:5000/game` (PC).

**사이트 다시 배포하기** (`web/` 폴더가 사이트 전체예요):
```sh
cd web
npx vercel deploy --prod
```

### 💻 로봇 없이 PC에서 (웹캠만 있으면 됨)
1. 프로젝트 폴더의 **`play_pc.bat`** 을 더블클릭합니다.
2. 브라우저가 자동으로 열립니다 → **http://localhost:5000/game**
3. 화면 오른쪽 위 **📷 카메라** 를 켜면 손짓으로 놀 수 있어요. (PC에서는 **꺼진 상태로 시작**해요)
4. 끝낼 때는 검은 창(서버)을 닫습니다.

### 📷 카메라 켜기 / 끄기
- 게임 화면과 메인 화면 오른쪽 위의 **📷 카메라** 스위치로 언제든 켜고 끌 수 있어요. 서버는 계속 켜져 있어요.
- 끄면 웹캠을 완전히 놓아 줘요 (웹캠 불이 꺼지고, 다른 프로그램이 바로 쓸 수 있어요).
- 꺼져 있는 동안은 손짓 교감·훈련·가위바위보·이리 와는 할 수 없고, 간식·재우기 같은 버튼 교감만 돼요.
  "함께 있는 시간" XP도 카메라에 손이 보일 때만 쌓여요.
- 처음부터 꺼진 상태로 시작: `python app.py --camera-off`

직접 실행하려면:
```sh
python app.py --no-robot --host 127.0.0.1 --camera-off
# 브라우저에서 http://localhost:5000/game → 📷 카메라 켜기
```

| 로봇 없을 때 | 동작 |
|---|---|
| 웹캠 손 인식 | ✅ 그대로 동작 (손짓, 훈련, 가위바위보, 이리 와) |
| 로봇 얼굴(OLED) | ✅ 웹 화면의 로봇 그림에 똑같이 표시 |
| 바퀴 움직임 · 부저 소리 | ⏸️ 생략 (말풍선과 표정으로 대신 보여 줌) |
| 레벨 · 호감도 · 앨범 저장 | ✅ 그대로 (`petgame.json`, `album/`) |

웹캠이 없으면 `python app.py --no-robot --cam -1` — 손 인식 없이 버튼으로 할 수 있는 것(간식, 재우기 등)과 화면을 볼 수 있어요.

### 🤖 라즈봇과 함께
```sh
~/razbot/run.sh
# 브라우저에서 http://<라즈베리파이 IP>:5000/game
```
화면 오른쪽 위 **"움직이기"** 를 켜야 바퀴가 움직여요 (기본 꺼짐).

## 4. 레벨별로 열리는 교감

| Lv | 열리는 것 | 하는 방법 |
|---|---|---|
| 1 | 👋 인사 | 손을 **빠르게** 좌우로 흔들기 (아침엔 "좋은 아침", 밤엔 "잘 자") |
| 1 | 🤚 쓰담쓰담 | 손을 **천천히 크게** 좌우로 |
| 1 | 🍪 간식 주기 | 버튼 · 하루 3번 |
| 1 | 💤 재우기 / 깨우기 | 버튼 |
| 2 | ✋ 하이파이브 | 손바닥을 펴고 **가만히** (0.7초) |
| 3 | 👍 칭찬 | 엄지 척 |
| 3 | 🎓 개인기 훈련 + 🌀 빙글빙글 | 훈련 탭 |
| 4 | 🙇 꾸벅 인사 (개인기) | 훈련 탭 |
| 5 | ✊ 가위바위보 | 버튼 → "가위, 바위, 보!" 구호에 맞춰 손 내기 |
| 6 | 🥺 먼저 놀자고 조르기 | 1분 넘게 안 놀아 주면 스스로 다가와요 (3번 무시하면 삐짐) |
| 6 | 💃 댄스 (개인기) | 훈련 탭 |
| 7 | 👉 이리 와 | 버튼 → 손을 보여 주면 그쪽으로 방향을 틀고 다가와요 |
| 8 | 💀 죽은 척 (개인기) | 훈련 탭 |
| 9 | 🥰 애교 부리기 | 행복도 80 이상이면 가끔 스스로 |
| 10 | 🎬 나만의 개인기 | 동작을 직접 골라 만들고 훈련 |

> 아직 안 열린 손짓을 하면 라즈봇이 **갸우뚱🤔** 하며 "Lv○에 배워요"라고 알려 줘요.
> 레벨이 낮을 땐(Lv1~2) 낯을 가려서 가만히 있을 때 꼼지락거리기만 해요.

**언제나 하는 반응**: 👊 주먹을 휘두르거나 들이밀면 깜짝 놀라 뒷걸음질치고 한동안 벌벌 떨어요.
오래 안 보이다가 나타나면 깜짝 놀라요 😮.

## 5. 🎓 개인기 훈련

진짜 강아지 훈련처럼 **신호 → 행동 → 보상**을 반복해요.

1. **훈련** 탭에서 개인기의 **🎓 훈련하기**를 누릅니다.
2. 화면에 나온 **신호 손 모양**을 카메라에 보여 줍니다 (12초 안에).
3. 라즈봇이 개인기를 시도해요. 숙련도가 낮으면 **엉뚱한 동작**을 하기도 해요.
4. 결과에 따라 8초 안에 알려 줍니다:
   - 맞게 했으면 → **👍 엄지 척** (또는 "잘했어" 버튼)
   - 틀렸으면 → **✋ 손바닥** (또는 "아니야" 버튼)

| 라즈봇 | 내 반응 | 숙련도 | 라즈봇 기분 |
|---|---|---|---|
| ✅ 맞게 함 | 👍 칭찬 | **+15%** | 💕 칭찬받았다! |
| ❌ 틀림 | ✋ 아니야 | +5% | 💪 다시 해 볼게! |
| ❌ 틀림 | 👍 칭찬 | **−5%** | 🤔 헷갈려… |
| ✅ 맞게 함 | ✋ 아니야 | 0% | 😢 잘한 건데… |
| 아무 반응 없음 | — | +3% / 0% | |

- 성공 확률 = 30% + 숙련도의 70% (숙련도 100%면 항상 성공).
- **숙련도 100% = 🏆 마스터!** 기념사진이 찍히고 +30 XP.
  이후엔 훈련하지 않아도 **신호만 보여 주면 언제든** 개인기를 해요.
- 훈련할 때마다 에너지가 4 줄어요.

### 개인기와 신호

| 개인기 | 레벨 | 신호 손 모양 | 동작 |
|---|---|---|---|
| 🌀 빙글빙글 | 3 | ☝️ 검지 하나 | 한 바퀴 돌기 |
| 🙇 꾸벅 인사 | 4 | ✌️ 브이 | 앞으로 숙였다 돌아오기 |
| 💃 댄스 | 6 | 🤘 검지+새끼 | 흔들기 → 돌기 → 앞뒤 → 반대로 돌기 |
| 💀 죽은 척 | 8 | 세 손가락 (검지·중지·약지) | 비틀거리다 멈춤(X X 눈) → 벌떡! |
| 🎬 나만의 개인기 | 10 | ✊ 주먹 (가만히) | 내가 만든 동작 순서 |

### 🎬 나만의 개인기 만들기 (Lv10)
훈련 탭 아래 **"나만의 개인기 만들기"** 에서 동작을 눌러 순서대로 담고(최대 8개) **저장하기**.
동작: 앞으로 · 뒤로 · 왼쪽 돌기 · 오른쪽 돌기 · 빙글 · 흔들흔들 · 삐! · 잠깐 멈춤.
동작을 바꾸면 **숙련도가 0%부터 다시** 시작해요.

## 7. 📋 오늘의 할 일 · 📸 추억

- 매일 **할 일 3개**가 새로 나와요 (레벨에 맞는 것 중에서). 예: 인사하기, 쓰담쓰담 3번, 훈련 3번, 가위바위보 3판, 함께 10분…
- 3개를 모두 끝내면 **🔥 연속 기록**이 1일 늘고 보너스 XP를 받아요. 하루라도 빠지면 1일부터 다시.
- **추억 앨범**: 레벨업과 개인기 마스터 순간에 카메라 사진이 자동으로 찍혀요.
  사진 오른쪽 위 **🗑️** 를 누르면 "정말 지울까요?"로 바뀌고, 3초 안에 한 번 더 누르면 사진이 지워져요(파일까지 삭제).
- **라즈봇 일기**: 레벨업, 마스터, 할 일 완료, 잠들기, 놀랐던 일 등이 기록돼요.
- **기록**: 오늘/총 함께한 시간, 누적 호감도, 가위바위보 전적(라즈봇 기준).

## 6-1. 🎵 라즈봇 목소리

> Pollen Robotics [microduck](https://github.com/pollen-robotics/microduck)의 목소리 합성(`sounds` — Apache-2.0)을
> 브라우저(Web Audio)로 옮겼어요. 코드: `web/static/voice.js`.

- **라즈봇마다 목소리가 하나씩** 정해져 있어요. 숫자 하나(목소리 시드)에서 음높이·음색(배음)·비브라토·떨림·꽥꽥거림·
  숨소리·말 빠르기가 정해져서, 같은 라즈봇은 늘 같은 목소리, 다른 라즈봇은 다른 목소리예요.
- 같은 소리도 매번 조금씩 다르게(변주) 내서 녹음 반복처럼 들리지 않아요.
- 감정 반응마다 목소리가 나요:

| 반응 | 목소리 |
|---|---|
| 👋 인사 | "꽥" 또는 "꽥꽥" (greet) |
| 😊 기쁨 · 하이파이브 · 개인기 | "짹짹" 지저귐 (chirp) |
| 🥰 쓰담쓰담 · 칭찬 · 잘 자 · 시무룩 | 낮고 부드러운 "구구" (coo) |
| 😮 놀람 · 😨 위협 | 높은 비명 (alarm) |
| 🥺 놀아줘 · 🤔 갸우뚱 | 끝이 올라가는 질문 소리 (inquire) |
| 🍪 간식 | 톡톡톡 쪼는 소리 + 짹 (peck) |
| 🎉 레벨업 · 마스터 | 신나는 "위이이~" (wheee) |
| ✊ 가위바위보 구호 | 톡 (peck) |

- 소리는 **게임 화면을 연 기기(PC·휴대폰) 스피커**에서 나요.

### 🔊 소리 조절 (화면 오른쪽 위 **🔊 소리** 버튼)
| 항목 | 조절 |
|---|---|
| 🎵 목소리 (이 기기) | 켜기/끄기 · **볼륨 슬라이더 0~100** · 들어보기 (이 브라우저에 기억됨) |
| 🔔 라즈봇 부저 (로봇) | **끄기 / 작게 / 보통** · 부저 시험(삐삐) |

부저는 켜고 끄기만 되는 부품이라 음량을 바꿀 수 없어서, **"작게"는 울리는 횟수는 그대로 두고 소리를 약 1/3 길이로 짧게** 울려요.

### 🔔 라즈봇 부저 (로봇 본체)
부저는 한 음만 낼 수 있어서, 감정을 **울리는 횟수와 길이**로만 구분해요 (`robot.py`의 `BUZZ`).

| 부저 | 감정 |
|---|---|
| 삐 (1번 짧게) | 👋 인사 · ✊ 가위바위보 구호 |
| 삐삐 (2번) | 😊 기쁨 · ✋ 하이파이브 · 🎭 개인기 · 이겼다 |
| 삐 삐 삐 (3번, 천천히) | 🥰 쓰담쓰담 · 👍 칭찬 · 🍪 간식 |
| 삐— 삐— (2번 길게) | 🥺 놀아줘 · 🤔 갸우뚱 |
| 삐——— (1번 아주 길게) | 😢 시무룩 · 😤 삐짐 · 🌙 잘 자 · 졌다 · 💀 죽은 척 |
| 삐삐삐삐삐 (5번 아주 빠르게) | 😮 놀람 · 😨 무서움 |
| 삐삐삐삐 (4번 빠르게) | 🎉 레벨업 · 🏆 마스터 · ⚽ 골 세레머니 |
- 브라우저는 화면을 한 번 눌러야 소리를 낼 수 있어요 → "🔇 화면을 한 번 누르면…" 안내가 보이면 눌러 주세요.
- 왼쪽 **🎵 목소리** 를 펼치면 목소리 특징(음높이·꽥꽥·빠르기·음색)과 감정별 **들어보기** 버튼,
  **🎲 목소리 다시 뽑기**(새 목소리로 바꾸기)가 있어요.

## 9. 자주 묻는 질문

- **손짓을 잘 못 알아들어요** → 📷 카메라를 펼쳐서 인식된 손 모양을 확인하세요. 손 전체가 화면에 들어오고 밝은 곳이 좋아요.
- **인사(빠르게)와 쓰담쓰담(천천히)이 헷갈려요** → 인사는 1.5초 안에 3번 이상 왕복, 쓰담쓰담은 크게 천천히 2번 이상 왕복.
- **"아직 몰라요"라고 해요** → 그 교감이 열리는 레벨이 아직 안 됐어요. 교감 도감에서 레벨을 확인하세요.
- **놀이 버튼을 눌러도 안 돼요** → 자고 있거나(깨우기), 에너지가 부족하거나(재우기), 다른 놀이 중이에요.
- **이리 와가 반대로 돌아요** (로봇) → `petgame.py` 의 `FOLLOW_SIGN = 1` 을 `-1` 로 바꾸세요.
